KIDOBITS LEVEL 5 — IMAGE PROMPTS (85 words)
========================================================================

HOW TO USE
1. Copy ONE prompt block at a time into Meta AI (or paste a whole
   lesson section if Meta accepts it).
2. Name each saved file exactly with the word plus .png  (e.g. car.png).
3. When done, zip them all and send the Drive link.

NAME THE FILES EXACTLY AS SHOWN. 26 of these words are only
2-6 letters and several repeat across lessons — the file name is
the only thing that keeps them straight.

STYLE (already inside every prompt - do not change)
Flat vector children-book illustration, thick clean outlines, bold
saturated colors, simple cheerful shapes, plain white background,
centered single object, no text, no letters, no words, square 1:1.

WATCH OUT: these words are abstract. Meta will try to render the
WORD as text. Pin the concrete object in the Thai description.
  said, one, two, have, all, know, wrong, out, now, air, hear,
  care, fair, enjoy, wanted, unhappy, redo, replay, short, little
